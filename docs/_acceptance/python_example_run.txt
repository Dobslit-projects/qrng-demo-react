== tratamento de erros ==
  401 esperado -> HTTP 403  corpo=b'{"request_id":"req_1792e38ef5da487a","error":"INVALID_TOKEN","message":"Token inv\xc3\xa1lido ou revogado."}'
  429 (cota/rate limit): capture KapuaError e faça backoff exponencial; não trate como sucesso, não reutilize bytes antigos.
  503 (upstream/entropia): capture KapuaError e faça backoff exponencial; não trate como sucesso, não reutilize bytes antigos.

Lembre-se: o token autentica e mede cota; não melhora a entropia. A caracterização física e a validação operacional da fonte continuam em andamento.
